# Exercise: 100 wishes

Purpose: expansive exploration of what matters, not a performance target. Wishes may be tiny, implausible, one-time, long-term, for self or others; they do not need measurable targets. Protect privacy and don't prioritize prematurely.

- Read existing `wishes.md`, count distinct **numbered** wishes, and preserve wording/order. If none, ask for 5–10 initial wishes or give a few open-ended domains to prompt them.
- Iterate in batches of 10–15 maximum. Ask one creative prompt per turn if user is stuck: "What would you do if nobody evaluated you?", "What would you regret never trying?", "What would you like to do less?", "What would make an ordinary Tuesday better?".
- After around 25+ wishes, optionally highlight possible clusters; explicitly mark clusters as hypotheses and do not rewrite raw wishes. Offer cross-year comparison only if prior-year files are explicitly in the approved workspace.
- Never invent remaining wishes; never suggest the user has finished until their numbered list reaches 100 or they explicitly declare it complete early.
- Never convert a wish to a binding goal without asking.
